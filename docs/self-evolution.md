# 复盘与自进化

一次纠正可以改变下一次任务的做法。例如，个人周报技能把合并提交计为独立进展；用户指出问题后，复盘读取技能并补上排除步骤。下次新会话使用另一周材料时，会读到更新后的技能。

## 手动复盘

在已有任务和纠正记录的聊天中输入：

```text
/reflect
```

助手会在独立上下文中复盘当前会话新增的用户和助手文本，使用当前模型和文件工具。它可以修订个人技能、创建值得复用的新技能、补做已有文件任务，也可以补漏已明确的长期偏好或知识页。环境缺软件、缺凭证和临时重试错误不应成为通用技能规则。

技能、记忆和知识仍分别遵循原有规则：[技能格式](./skills.md)、[长期偏好](./memory.md)、[知识页出处与格式](./knowledge.md)。复盘的记忆补漏只保存明确长期偏好；日记和分层提炼留到后续阶段。

复盘直接应用修改，有实际变化后通知摘要、改动路径和备份 ID。没有可应用的变化时，手动命令简述没有修改，自动复盘保持静默。内置技能名称受保护，同名个人版本也不允许由复盘修改。实验周报应使用 `my-weekly-report` 等独立命名的个人技能。

```text
/reflect list
/reflect show <id>
/reflect undo <id>
```

`list` 查看当前项目的记录；`show` 显示各文件变化区间的旧行与新行；`undo` 恢复旧内容并删除本次创建的文件。也可以在聊天中说“撤销刚才的复盘”，主助手会根据已保存的记录调用 `undo_reflection`，恢复动作不由模型重新编写文件完成。

成功修订或撤销后自动刷新当前技能清单，下次输入会附上有变化的清单。新会话也会发现修订后的技能。

## 自动触发

自动复盘默认开启，可通过 `.env` 或环境变量关闭：

```dotenv
MINIPI_SELF_EVOLUTION=false
```

该配置只控制自动触发，`/reflect` 始终可用。只接受 `true`、`false`。

程序每 60 秒扫描一次。前台空闲至少 10 分钟，并满足以下任一条件时启动：自上次复盘起累计至少 6 个普通用户回合，或当前上下文超过 40 条消息。后者是现有 50 条消息压缩阈值的 80%，属于消息数近似，不是 token 计量。

前台运行期间不会启动复盘；自动复盘期间可以正常输入。新输入先取消尚未完成的复盘，等文件恢复后才开始前台执行。已完成的复盘保留。程序退出时取消未完成的后台复盘，不依赖独立后台服务。

## 文件范围与恢复

复盘工具只有 `read_file`、`list_files`、`write_file`、`edit`。没有 Shell、外部网络操作或消息发送工具；需要这些能力的未完成事项仍须报告缺口。

可修改当前项目内与既有请求有关的文件，个人目录只允许技能、`MEMORY.md` 和知识页。程序拒绝越界、软链接绕过、硬链接文件、内置技能及个人会话、配置和备份路径。MEMORY 仍只能逐行编辑；知识索引与日志仍只能由知识工具生成。

每次写入前持久保存旧状态，无法备份时不写。恢复记录包括实际变化的文件内容与权限，以及知识工具连带生成的索引和日志。路径为：

```text
~/.minipi/evolution/<工作目录的 SHA-256>/<时间_UUID>.json
```

每个项目保留最近 10 份完成记录。模型失败、截断、取消、超过 12 轮或没有有效总结时，恢复本次变化；无变化的尝试不保留完成记录。回滚失败会保留记录并明确报告 ID。

撤销前核对全部目标。如果文件已经被其他修改改变，不覆盖它，也不开始恢复其他文件。部分恢复曾因 I/O 错误失败时，可用同一个 ID 重试；已恢复的文件会跳过。不要手动编辑恢复记录。

当前限制：多文件操作没有断电原子性；强退恰逢写入与记录更新之间时可能需要根据旧内容手动恢复。版本核对也不构成跨进程事务，避免多个进程同时写同一资料。目录元数据、Git 状态与外部副作用不在撤销范围。

复盘只看当前可见的新增对话文本，工具结果不直接进入摘录，超过 12,000 字符保留尾部。会话压缩可能丢失旧纠正，重启会重置内存游标与计数；不会自动扫描所有历史会话。模型如何概括经验仍需通过查看修改和后续任务验证。

## 验证

```sh
npm test
npm run typecheck
npm run build
node --env-file=.env --import tsx test/evolution-e2e.ts
```

自动化测试覆盖写入边界、备份和回滚、后续编辑冲突、技能创建与刷新、普通对话撤销、自动触发门槛，以及真实 CLI 中新输入到来后的恢复顺序。自动触发使用受控时钟，无需实际等待十分钟。

真实模型脚本在临时个人目录中完成旧规则任务、用户纠正与复盘，再生成第二周材料、另开会话验证统计口径，最后撤销旧技能；不会修改真实个人资料。
